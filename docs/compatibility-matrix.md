# 互換性マトリクス

この表では、仕様書で動作を確定できた機能と、旧VB6実行ファイルから存在だけを確認できた機能を分けています。
パナソニックの警報4種とエレベータ連動は今回追加した機能で、比較対象となる旧アプリの実装はありません。
「実装済み」はビット単位のbuild／parseと自動試験があることを意味します。

## VB6版で存在を確認した追加機能

次は旧VB6版 Ver.0.84.22 に画面またはリソースが存在しますが、手元の仕様書11冊には対応仕様がありません。
そのため、現段階で「完全互換」とは判定していません。

| 追加系統 | 現状 | 完全実装に必要な根拠 |
|---|---|---|
| 外部移報の複数世代・機種別割当／自動復旧 | Q49共通部と汎用ターミナルで部分代替 | 世代別通信仕様または正常・異常キャプチャ |
| VHX／DASH WISM擬似ホーチキ | 未実装（生電文調査のみ可能） | 通信仕様、機種別制約、期待応答 |
| DASH VHX中継器 | 未実装 | ポーリング、DC1、Q0～Q2、E2～E6等の仕様またはソース |
| EV充電連動 | 未実装 | NG1～NG4、箱／住戸割当、状態要求の仕様またはソース |
| MCの業務別状態DB・一括自動応答 | 台帳で応答コマンドが確定する要求へ自動応答（ADDRは受信電文から引き継ぎ）。一括応答と業務ペイロードは未実装 | コマンド別状態遷移と業務ルール |
| EVの周期CHECK・ECALL後監視・自動ESTAT | ECALL受信時のESTAT／ESTOP自動応答を4.5.1⑨⑩⑪に基づき実装。周期CHECKとECALL後の状態監視は未実装 | 自動運転の期待タイミングと状態遷移 |
| 4ポート通信基板試験 | 1ポートの共通通信基盤まで | 基板I/O仕様、試験項目、合否条件、4ポート実機 |
| その他の製品固有画面 | プロファイル拡張待ち | 対象機種と期待する電文・状態遷移 |

## 完全上位互換へ進める条件

1. 上表の未確定機能ごとに、仕様書・VB6ソース・実機キャプチャのいずれかを揃える。
2. 正常系だけでなく、タイムアウト、NAK、BCC異常、衝突、途中切断の期待結果を確定する。
3. 4ポート同時試験などハードウェア依存項目は、対象変換器と実機で結合試験する。
4. 確定した電文をgolden vectorとして追加し、UI操作と配布版の回帰試験に組み込む。
